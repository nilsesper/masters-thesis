\label{sec:DTData}

For this work, atmospheric muon data was recorded with the \ac{DT} chamber at the cosmic test stand in Aachen (sec.\ \ref{sec:CMS-AachenTestStand}). This section presents the recorded dataset and the analysis strategy to reconstruct muon tracks without an external trigger. The triggerless reconstruction is essential, because the developed readout chain for the scintillation detector (sec.\ \ref{sec:Scint}) should be validated using the \ac{DT} chamber hits as reference (sec.\ \ref{sec:Combined}). Therefore, using the scintillator as a trigger for the chamber would imply a bias.
\newline The reconstruction strategy is guided by the local \ac{CMS} \ac{DT} reconstruction \cite{DT-LocalReco} and calibration procedures \cite{DT-OfflineCalibration}, as well as other work within the \ac{DT} group concerning track reconstruction \cite{MSc-Alcalde,CMS-NOTE-2008-017}. The reconstruction was implemented into a custom standalone code framework \cite{dt-scint-analysis-tools-Main}, which allows the analysis of the \ac{DT} chamber data as well as the scintillator data (sec.\ \ref{sec:ScintData}). Integration with the central \ac{CMS} \ac{DT} reconstruction framework might be desired in the future, to exploit the evolved algorithms. However, the aim of this thesis is a proof-of-concept measurement with the \ac{DT} chamber and the scintillator. Therefore, the reconstruction strategy inside this self-developed framework is considered sufficient.

\label{sec:DTData-Testpulse}
Precise time measurement of the drift cell hits is essential for a successful \ac{DT} reconstruction, as the measured timestamps are directly used to calculate the hit position within the drift volume (sec.\ \ref{sec:GaseousDetectors-DriftChamber}). Because of this, it must be ensured that the readout of all channels of the \ac{DT} chamber is actually synchronized \cite{DT-OfflineCalibration}. 

\subsection{Testpulse generation}
\label{sec:DTData-Testpulse-Generation}
\paragraph{Synchronous testpulse generation}
As described in sec.\ \ref{sec:CMS-DTMinicrate}, the minicrate can generate synchronous testpulses for the chamber's \acp{FEB}, which send back responses to the \acp{OBDT}. The issuing of testpulses is controlled by the \ac{DT} backend. It can send a command to all \acp{OBDT} to generate a testpulse at a given $BX$ time in an orbit (a new orbit starts at $BX=0$ and $TDC=0$, as discussed in sec.\ \ref{sec:CoordinateFrame-TimestampFormat}). Therefore, the time when the testpulse is issued is precisely known.
\paragraph{Testpulse latency correction}
The testpulse generators of the \ac{OBDT} phi and \ac{OBDT} theta boards have different analog circuitry which produce the actual testpulses (sec.\ \ref{sec:CMS-Phase2Readout}). This results in a latency difference between the boards. However, the latency difference is constant, as it originates from the (static) circuit. In order to eliminate this timing offset between \ac{OBDT} flavors, a correction should be applied to the recorded testpulse hit timestamps. The time difference of the generated testpulse output was measured with an oscilloscope. A screenshot of the measurement can be found in the appendix in fig.\ \ref{fig:DTData-Testpulse-LatencyDifference}. The resulting time difference between the \ac{OBDT} boards is:
\begin{equation}
    T_\text{testpulse, theta} - T_\text{testpulse, phi} = (116 \pm 1)\;\si{\nano\second}.
    \label{eq:DTData-TestpulseLatency}
\end{equation}
This latency correction value is applied to the recorded timestamps of the testpulse hits.
\newline Additionally, the testpulse cable lengths from the minicrate to the \acp{FEB} in the chamber are not all the same. To account for latency differences due to the different cable lengths, the difference in signal propagation time was measured with an oscilloscope and applied to the affected channels as well.

\subsection{Testpulse response and timing calibration}
\label{sec:DTData-Testpulse-Calibration}
A testpulse run is recorded, where all \ac{DT} chamber channels are unmasked in the \ac{OBDT} to record the testpulse \ac{FEB} responses. Since the time of the testpulse generation is fixed w.r.t.\ the orbit counter, one can use the time relative to the beginning of the respective orbit for this analysis, which is defined as
\begin{equation}
    T_\text{orbit} = T(OC,\;BX,\;TDC) - T(OC,\;BX=0,\;TDC=0).
\end{equation}
For the presented testpulse run, the pulses were commanded to be sent at $BX=50$ of each orbit. According to eq.\ \ref{eq:Timestamp}, this translates to $T_\text{orbit}=\SI{1600}{\tu}$. The testpulse response should come later than this time, as one has to expect several delay sources for the received response: The latency of the testpulse generation circuitry, the propagation time via the testpulse cables, the \ac{FEB} intrinsic response time as well as the frontend cable lengths going from the \acp{FEC} back to the \ac{OBDT}.
\paragraph{Testpulse response}
The timestamps of all received testpulses for each channel are averaged to obtain one testpulse time value per channel $\left\langle T_\text{orbit}(\text{SL, Ly, Wi}) \right\rangle$. Here, the individual channels are specified with the Superlayer (SL), Layer (Ly) and Wire (Wi) indices of the drift cell in the chamber. 
\newline Fig.\ \ref{fig:DTData-TestpulseResponse} shows the testpulse response for all channels of the \ac{DT} chamber. The timing uncertainties are calculated from the digitization step of the \ac{OBDT} (\SI{0.78}{\nano\second}) and the uncertainty of the latency correction (sec.\ \ref{sec:DTData-Testpulse-Generation}).
\begin{figure}[htb]
    \centering
    \includegraphics[width=\textwidth]{dt_tp/t_orbit.pdf}
    \caption{Mean timestamp $\left\langle T_\text{orbit}(\text{SL, Ly, Wi}) \right\rangle$ of the testpulse responses for all individual channels.}
    \label{fig:DTData-TestpulseResponse}
\end{figure}
\newline One can observe that all read-out channels do actually receive a testpulse response. From this, it is concluded that there are no dead channels on the \ac{OBDT} side and the installed minicrate is working correctly. Also, one can see that the \acp{FEB} are all operational.
\newline As expected, the testpulse response is recorded at timestamps greater than the time $T_\text{orbit}=\SI{1600}{\tu}$ when the testpulse generation is commanded. The recorded response timestamps lie in the range $T_\text{orbit}\approx 1705-1720 \;\si{\tu}$. While for the phi superlayer (\acp{SL} 1, 3) the interval of all response timestamps is comparable, the response of all channels of the theta superlayer (\ac{SL} 2) is systematically later by approximately $10\;\si{\tu}$ ($8 \;\si{\nano\second}$). One reason is the length of the \ac{FEC} cables, which contributes to the response timing. Since the minicrate is mounted on the chamber side with the phi superlayer \acp{FEC}, the phi cables are significantly shorter ($\approx 0.3-1.6\;\si{\meter}$) than the theta cables ($\approx 3\;\si{\meter}$). A cable length difference of $\approx\SI{2}{\meter}$ explains a timing difference in the order of magnitude that is observed.\footnote{With the rough assumption of an electrical signal propagation velocity of $\approx\SI{20}{\centi\meter/\nano\second}$, one obtains an expected delay of \SI{10}{\nano\second} for a cable length difference of \SI{2}{\meter}.} Since this difference in frontend cable length is part of the signal path, it is right to correct for this in the timing calibration.
\newline Another observation is the difference in the channel-to-channel variations between the phi and theta superlayers. While the testpulse responses for \ac{SL} 2 (theta) are contained within a window of only \SI{5}{\tu} (\SI{4}{\nano\second}), the channels vary by up to \SI{10}{\tu} (\SI{8}{\nano\second}) for the \acp{SL} 1 and 3 (phi). This is explained by the fact that \ac{FEC} cables of the phi superlayers are not uniform in length, as it is the case for the theta (see mentioned values above). One would expect that the cable length affects groups of channels that are connected to the same cable in the same way.
\newline However, one can also observe timing offsets between channels of the same wire index, between different layers in \ac{SL} 1 (phi). This cannot be explained by the cable length variation, as channels of the same wire index share the same cable. Because there seems to be a systematic shift between channels of layers $(0, 2)$ and $(1, 3)$, this effect may be related to an offset in the \ac{TDC} unit inside of the \ac{OBDT}.
\paragraph{Extracted timing correction}
The relative timing correction for all channels can now be calculated. For the correction, it is decided to use the global average of testpulse times $\left\langle T_\text{orbit} \right\rangle$ as a reference time. The relative timing correction $T_\text{corr}$ for the individual channels can be estimated by subtracting the channel timestamp by this reference time:
\begin{equation}
    T_\text{corr}(\text{SL, Ly, Wi}) = \left\langle T_\text{orbit}(\text{SL, Ly, Wi}) \right\rangle - \left\langle T_\text{orbit} \right\rangle.
\end{equation}
Note that because the latency correction was performed (eq.\ \ref{eq:DTData-TestpulseLatency}), the obtained timing correction covers the full readout path (from \ac{FEB} over the cables to the \acp{OBDT} and the path to the \ac{DT} backend), but not the variations in the testpulse generation, which is desired. The extracted corrections are shown in fig.\ \ref{fig:DTData-TestpulseCorrections}.
\begin{figure}[htb]
    \centering
    \includegraphics[width=\textwidth]{dt_tp/t_corr.pdf}
    \caption{Calculated relative timing corrections $T_\text{corr}(\text{SL, Ly, Wi})$ for all individual channels.}
    \label{fig:DTData-TestpulseCorrections}
\end{figure}
\newline The obtained timing corrections lie in the range of $-6\;\si{\nano\second}$ to $+7\;\si{\nano\second}$. In comparison, the \ac{CMS} \ac{DT} offline calibration note \cite{DT-OfflineCalibration} states usual timing calibration values of up to $\pm 9\;\si{\nano\second}$. Thererfore, the result from the testpulse run presented above seems to yield calibration values in the expected range. When applying these corrections to the obtained testpulse response times (fig.\ \ref{fig:DTData-TestpulseResponse}), one would obtain a distribution which is flat in time.

Note that the data presented here has the timing correction from the testpulse run (sec.\ \ref{sec:DTData-Testpulse-Calibration}) already applied.

The full dataset contains a total of \num{316757979} drift cell hits. Fig.\ \ref{fig:DTData-ChamberRates} shows the cell occupancies of all individual wires of the chamber. \paragraph{Comparison with CMS}
Different \ac{CMS} publications present hit rates which lie in the range $\approx 30-60\;\si{\hertz}$ per cell \cite{CMS-Main,CMS-DT-TestBeam-2004}. These rates are slightly higher than what is observed in the recorded dataset from the test stand. The presumably higher noise in the \ac{CMS} data may be related to older readout electronics that were used at the time, as the new minicrate was not available yet. A lower \ac{FEB} threshold voltage might also lead to an increased hit rate. The threshold of the cited \ac{CMS} values is not known, but might have been lower than the selected \SI{35}{\milli\volt} (tab.\ \ref{tab:MB1Chamber-Settings}) used in this work, which is a relatively high value.

\paragraph{Comparison with cosmic rate} A comparison of the measured cell rates to the rate expectation solely from atmospheric muons should be made in this paragraph. In principle, the expected rate can be calculated if one solves the solid angle and area integrals of the muon flux for particles above the energy detection threshold (eq.\ \ref{eq:CosmicMuon-DetectorRate}), as was discussed in sec.\ \ref{sec:AtmosphericMuons-Cosmics}. However, for non-spherical geometries this integration is non-trivial.
\newline Alternatively, it is possible to estimate the rate with a \ac{MC} simulation. The developed analysis code includes this possibility of simulation: It can randomly generate muon tracks which follow the atmospheric muon rate and angular distribution and propagate them through the detector geometry. Note that the simulation does not model the physics of the muon interacting with the detector material, but simply simulates the geometric tracks and detects intersections with sensitive cell volume. However, the simulation respects the finite hit efficiency of the \ac{DT} cells (sec.\ \ref{sec:CMS-DTPerformance}) and models the dead cells found in the real chamber (tab.\ \ref{tab:DTData-DeadWires}). More details on this simplified simulation are discussed in appendix \ref{sec:Simulation}.
\newline The simulation yields an average atmospheric muon rate of $(14.341 \pm 0.006)\;\si{\hertz}$ for a phi drift cell and $(12.303 \pm 0.007)\;\si{\hertz}$ for a theta drift cell (tab.\ \ref{tab:Simulation-ChamberRates}). These values are approximately $50\%$ smaller than the observed cell rates of the \ac{DT} chamber at the test stand. The higher observed cell rate could be explained with the presence of noise hits in the real detector, as the simulation performed here does not include any modeling of noise. Even though there is a deviation, the order of magnitude of $\mathcal{O}(10^1\;\si{\hertz})$ per cell is still similar to what is observed in data. Together with the fact that the cell rates cited in \ac{CMS} publications for cosmics are also in a similar order of magnitude, it is concluded that the recorded \ac{DT} data is plausible and that the \ac{DT} chamber operates nominally.

\paragraph{Poisson background}
One can observe that the time difference between hits decreases exponentially. This behavior continues to the right beyond the plotted range. Both cosmic muon hits and noise are random events which can be described by a Poisson distribution. From statistics, it is known that the time difference between Poisson events is exponentially distributed \cite{Book-KolanoskiWermes}. Therefore, this behavior is expected and confirms the random nature of the recorded cell hits.
\paragraph{Secondary hits}
In the region $\approx 0-500\;\si{\nano\second}$, another feature is visible which dominates over the exponentially decreasing behavior. Apparently, there are secondary hits detected a short time after the initial hit. The observed structure of these secondary hits is analyzed in the following. For this, the Poissonian \enquote{background} due to random noise events should be subtracted to analyze the shape of secondary hits in time. For this, an exponential function is fitted to the exponentially decreasing part of the histogram (fit range: $\Delta T_\text{cell} \geq \SI{1000}{\nano\second}$). Fig.\ \ref{fig:DTData-CellHitDifference-ExpFit} in the appendix shows the fit result.
\newline Fig.\ \ref{fig:DTData-CellHitDifference-NoBg} shows the resulting distribution after extrapolating the exponential \enquote{background} to the left and subtracting it. A structure of two peaks can be observed, where the second peak is more narrow than the first one. Also, one can observe a dead time of $\approx\SI{40}{\nano\second}$ in the plot, which might originate from the \acp{FEB} in the chamber or the \acp{OBDT} themselves.
\newline Note that the structure with the secondary peaks was not originally discovered in this work, but is a known effect. Two \ac{CMS} Notes \cite{CMS-NOTE-2008-003,CMS-NOTE-2010-004} also show a distribution of secondary hits which looks similar in shape. In fig.\ \ref{fig:DTData-CellHitDifference-CMSNote} the observed distribution of the secondary hits from one of these publications is shown for comparison. \paragraph{Physical origin}
The observation that the secondary peaks lie in the time range of $\Delta T _\text{cell}\approx 200-600\;\si{\tu}$ ($156-468\;\si{\nano\second}$) already hints that these hits might have a physical cause and are not created by reflections in the readout electronics, as the electron drift time in a \ac{DT} cell lies in this order of magnitude (eq.\ \ref{eq:DT-MaxDriftTime}).
\newline Two physical effects play a role in the creation of secondary peaks: When the electrons in the drift cell arrive at the wire, an avalanche forms and the charge is amplified. In this avalanche, photons may be created, whose movement is not constrained by the electric field in the cell. The \ac{DT} cell includes two metal electrodes apart from the anode wire (fig.\ \ref{fig:DT-Cell}): The field shaping electrodes which are relatively close to the wire, and the cathode strips which are roughly \SI{21}{\milli\meter} (i.e.\ half of the cell width) away from the wire. The photons can hit these electrodes and create a secondary ionization event through the photoelectric effect. The created photo-electrons from this secondary ionization drift again towards the wire, creating a secondary hit after the first one. Since the drift cell is constrained in size, the timestamps of the secondary hits also have a maximum.\footnote{When the ionization takes place somewhere else on the cell wall, the electrons are most likely lost and cannot reach the wire, due to the shape of the electric field lines.} The two-peak structure observed in the data can therefore be explained with photo-electrons originating from the field shaping electrodes (first wide peak) and the cathode strips (second narrow peak). These peaks are in the following referred to as photo-peaks \cite{CMS-NOTE-2008-003}.
\newline The second physical effect responsible for secondary hits are so-called $\delta$-electrons. The energy loss of the passing muon is Landau-distributed, allowing larger energy losses in few collisions, which lead to high energy electrons in the gas volume (sec.\ \ref{sec:Interactions-Ionization}). These electrons may ionize the gas themselves, which can also contribute to secondary hits at the wire. Depending on the movement direction of the $\delta$-electron, not only after-pulses, but also pre-pulses may be created. The effect of $\delta$-electrons to the double peak structure is considered small compared to the photo-peaks, according to the \ac{CMS} Note \cite{CMS-NOTE-2008-003}.

\subsection{Drift velocity estimation with photo-peak}
\label{sec:DTData-CellHits-DriftVelocityEstimation}
The second photo-peak can be used to estimate the drift velocity of the electrons in the \ac{DT} cell, without the need of an external trigger or performing a track reconstruction. This method was introduced in \cite{CMS-NOTE-2008-003}, where it was however only used for relative drift velocity measurements $\delta v_\text{drift}/v_\text{drift}$, not the absolute value $v_\text{drift}$.
\paragraph{Photo-peak method}
As discussed above, the second (narrower) photo-peak originates from photo-electrons created at the cathode strip, which is located on the cell walls at roughly $d/2=\SI{21}{\milli\meter}$ distance from the wire. Assuming that the avalanche takes place very close to the wire and neglecting the photon travelling time, one can consider the peak position of the photo-peak as the drift time of the created photo-electron from the cathode strip to the wire. A parabolic fit to the second photo-peak is presented in fig.\ \ref{fig:DTData-CellHitDifference-PeakFit}. From the goodness-of-fit value and the residual plot it is concluded that the peak fit is acceptable, even though it is clear that the peak is asymmetric, and the parabolic fit therefore only is a first-order estimation.
\begin{SCfigure}[50][htb]
    \centering
    \includegraphics[width=0.5\textwidth]{large_combined_data_plots/53_comb__DT_HITS_NODEADTIME_DIFF_SPECIFIC_PEAKFIT.pdf}
    \caption{Parabolic fit to the second narrow peak in the time difference distribution of secondary hits.}
    \label{fig:DTData-CellHitDifference-PeakFit}
\end{SCfigure}
\newline With the obtained photo-peak position $t_\text{pp}=b=(414.96 \pm 0.10)\;\si{\nano\second}$ and an uncertainty on the drift distance of $\sigma_{d/2}\approx\SI{100}{\micro\meter}$ (which was the requirement during the chamber construction \cite{CMS-Main}) one can estimate the drift velocity as
\begin{equation}
    v_\text{drift}=\frac{d/2}{t_\text{pp}}\approx ( 50.5 \pm 0.2 )\;\si{\frac{\micro\meter}{\nano\second}}.
    \label{eq:PhotoPeak-DriftVelocityEstimation}
\end{equation}
Of course, this value assumes a constant drift velocity over the full drift distance, which in reality is not exactly the case. Another unregarded fact is the vertical extent of the cathode strip. This means that photo-electrons may also drift towards the wire from a different height, leading to a longer drift distance than the assumed half cell width $d/2$ and consequently a longer drift time. It therefore becomes clear that the obtained position of the photo-peak can not be directly related to the maximum drift time, and that one should further understand the described geometric effect of longer drift distances.
%\newline Within the scope of this thesis, no further simulation studies are performed, which would however be needed to account for this effect and to derive an average (effective) drift distance $x_{D,\text{eff}} > d/2$ which might be able average out this geometric effect and would allow the calculation of the drift velocity as $v_{D}=x_{D,\text{eff}} / t_\text{pp}$. 
\paragraph{Comparison to CMS}
The obtained value for the drift velocity in eq.\ \ref{eq:PhotoPeak-DriftVelocityEstimation} above is smaller than the expectation in the \ac{DT} system of $\SI{54.5}{\micro\meter/\nano\second}$ (eq.\ \ref{eq:DT-DriftVelocity}). However, the described geometric effects might be able to explain the smaller value, although quantitative studies were not performed yet. Still, the resulting velocity lies in the expected order of magnitude of $\mathcal{O}(\SI{50}{\micro\meter/\nano\second})$.
\newline In the CMS Note \cite{CMS-NOTE-2008-003}, the photo-peak method was only used to estimate the relative change in drift velocity $\delta v_\text{drift} / v_\text{drift}$, never the absolute value $v_\text{drift}$ itself. If one tries to calculate the drift velocity with the photo-peak position from the \ac{CMS} plot in the same way as presented above, one would obtain a drift velocity of $v_\text{drift}\approx\SI{52.8}{\micro\meter/\nano\second}$ (estimating the peak position from fig.\ \ref{fig:DTData-CellHitDifference-CMSNote} as $t_\text{pp}\approx\SI{510}{\tu}\approx\SI{398}{\nano\second}$). This value is also lower than the expected value of $\SI{54.5}{\micro\meter/\nano\second}$ (eq.\ \ref{eq:DT-DriftVelocity}).
\newline From this, one can conclude that the photo-peak method is not capable of measuring the drift velocity in terms of absolute value without calibration. The absolute calibration may include simulation studies of the photo-electron drift behavior and effective distance. Studies at the \ac{DT} test stand involving a reference measurement with the \ac{VDC} monitoring hardware \cite{DT-VDC-System} could be imagined in the future.
\paragraph{Assumption for drift velocity in this work}
Because of the observed uncertainties in deriving the electron drift velocity from the recorded dataset with the photo-peak method, it is decided here that in the following the \ac{CMS} reference value of $v_\text{drift}\approx\SI{54.5}{\micro\meter/\nano\second}$ is used (eq.\ \ref{eq:DT-DriftVelocity}). This reference value is plausible, because the gas mixture and high voltage values are chosen similarly to \ac{CMS} (sec.\ \ref{sec:CMS-AachenTestStand}). In principle, it would also be possible to extract the drift velocity from the track fits (sec.\ \ref{sec:DTData-SLPatternFitting}). However, in the simple reconstruction strategy employed in this work, this parameter is fixed to the reference value. %It is clear that the assumption implies a bias on the reconstruction results, which is accepted here.

\subsection{Drift cell dead time}
\label{sec:DTData-CellHits-DeadTime}
As discussed above, there are occasions where secondary hits in the \ac{DT} cells can occur (sec.\ \ref{sec:DTData-CellHits-SecondaryHits}). If a track reconstruction is being attempted with these hits, one will obtain tracks which do not originate from a passing muon. As these secondary hits usually originate from photons escaping the electron amplification avalanche near the wire, the easiest way to suppress them is to apply a dead time to each individual \ac{DT} cell.  The dead time covers the time interval where the secondary hits occur. Of course this is not necessarily helpful in the case of $\delta$-electrons, as they also create pre-pulses and not only after-pulses. In the case of a pre-pulse, the dead time would lead to a loss of the \enquote{real} hit and therefore a wrong hit selection.
\newline Since this analysis does not aim at optimized precision but rather at a proof-of-concept measurement of the \ac{DT} chamber in combination with the scintillator readout, this small bias is accepted. In the following, a dead time of \SI{600}{\tu} (\SI{468}{\nano\second}) is applied to all individual cells to suppress the effect of secondary hits.
\paragraph{Cell occupancy after dead time}
The application of the dead time reduces the total number of cell hits in the dataset to \num{297312727} ($\approx 93.9\%$ of the initial count). The average rate of active cells consequently reduces slightly, to a value of $(25.111 \pm 0.001)\;\si{\hertz}$.





\section{Superlayer hit clustering}
%\begin{itemize}
%    \item Triggerless reconstruction: Need to consider all recorded hits as potential muon signature
%    \item Cluster hits within maximum drift time window
%    \item Pattern rate discussion
%    \item Compare to rates of fake patterns (to estimate noise influence)
%\end{itemize}
\label{sec:DTData-SLHitPatterns}
The first step in the reconstruction of tracks in the \ac{DT} chamber is the selection of cell hit candidates, which may be part of a muon track. Since the reconstruction is triggerless, no external trigger signal can be used for this purpose. Instead, all recorded cell hits must be treated as potential track hit candidates and consecutively filtered out. The hit selection in this step is based on the geometry of consecutive hits and their temporal distance.
\subsection{Track candidate patterns}
\label{sec:DTData-SLHitPatterns-TrackPatterns}
\paragraph{SL track patterns}
A muon track leaves ionization charges and consequently a hit in cells of the different layers of the \ac{DT} chamber. Depending on the track angle, different cell hit patterns can be produced. Fig.\ \ref{fig:DTData-SLPatterns} shows possible hit patterns in one superlayer, under the assumption that all four cells are triggered. It is clear that, depending on the inclination of the muon track, different patterns can be produced. Note that in reality not all cells are always hit due to detector inefficiencies (sec.\ \ref{sec:CMS-DTPerformance}). In this thesis, it is only attempted to reconstruct tracks from the patterns $0-5$ in fig.\ \ref{fig:DTData-SLPatterns}, which have four cell hits.
\begin{figure}[htb]
    \centering
    \includegraphics[width=0.9\textwidth]{SL-Patterns.pdf}
    \caption{Possible \ac{SL} hit patterns created by muon tracks, with four cell hits. Only the patterns $0-5$ are considered for the analysis in this thesis.}
    \label{fig:DTData-SLPatterns}
\end{figure}
\paragraph{Pattern timing}
Depending on the position of the muon track within each cell, the distance from the wire that the electrons need to drift along varies, which results in the hits of the pattern not having the same timestamps. However, one can formulate an upper bound of the timestamp differences of cell hits of a pattern, which might belong to a muon track. This upper bound is given by the maximum drift time $t_\text{drift,max}$ (eq.\ \ref{eq:DT-MaxDriftTime}), because of the given cell size:
\begin{equation}
    \Delta T_\text{max} = \max \left\{ \left | T_{ly=i} - T_{ly=j} \right | ; \; i,j=0,1,2,3 \right\} \leq t_\text{drift,max} \approx \SI{385}{\nano\second}.
    \label{eq:DTData-PatternTimeWindow}
\end{equation}
Here, $T_{\text{Ly}=i}$ is the hit timestamp of the respective cell hit in layer $i$ of the superlayer. Of course, this is only valid if one assumes simultaneous creation of the ionization in all four cells. Since the cosmic muons travel approximately with the speed of light and one superlayer measures only $\SI{5.4}{\centi\meter}$ in height (sec.\ \ref{sec:CMS-AachenTestStand-Phase2Setup}), this assumption can be justified.
\paragraph{Pattern finder algorithm}
The algorithm which was implemented to identify the patterns is briefly described here. It is capable of finding patterns in the recorded cell hits over a full superlayer and is event-loop based. First, all hits are sorted by their timestamp. Then, the algorithm loops through the hit list one by one and stores the current hit in a matrix containing the latest hit of each cell. After the matrix was updated with the current hit, all possible patterns which contain the most recently added hit are checked. If any of the checked patterns shows a maximum time difference between all hits $\Delta T_\text{max}$ smaller than the selected maximum timestamp difference $t_\text{drift,max}$, the pattern is constructed and stored.
\newline Note that because this algorithm checks for new patterns with each new hit, it is possible that multiple patterns are constructed in the event of more than four hits lying close in time. This might be the case for noise hits close to the \enquote{real} track, or if a high energy particle creates showers in the chamber. The fact that there may be several patterns very close in time at the same position in the superlayer is revisited in sec.\ \ref{sec:DTData-SLFitGrouping} later.
\paragraph{Applied selection criteria}
The goal of this analysis is to accomplish a track reconstruction algorithm which is simple and can be used for cross-checks with the developed scintillator readout system, and not to conduct precision measurements. Therefore, a not fully complete selection of patterns is considered sufficient. As explained, only superlayer patterns with four hits are accepted and not less. In principle (depending on the assumptions) it is possible to also use three-hit patterns for the analysis, however in this thesis this is not the case. Also, regarding the pattern shape, only the patterns with indices $0-5$ are considered. The patterns $6-7$ introduce additional difficulties in the reconstruction without a trigger and are therefore neglected here. Tab.\ \ref{tab:DTData-PatternSelection} summarizes the pattern selection criteria used in this work.

\subsection{Fake patterns}
\label{sec:DTData-SLHitPatterns-FakePatterns}
This section further investigates the influence of noise by searching for \enquote{fake patterns}, i.e.\ patterns that can not originate from muon tracks (suggested by \cite{PrivateComm-Hebbeker}). Analysis of the rate of these patterns could provide information on the order of magnitude of the fraction of noise in the track-like patterns.
\paragraph{Influence of noise hits}
It is clear that the observed noise in the single-cell hits can propagate through the pattern finding algorithm and generate patterns which do not originate from a muon track. For the track-like patterns the resulting rate is a combination of \enquote{real} muon tracks and noise. However, the noise will also produce patterns with other geometries, that are impossible to create with a muon track.\footnote{In principle, there is a possibility that more exotic patterns are formed from real particle crossings. This may be due to showering of high energy particles or due to Coulomb scattering (sec.\ \ref{sec:Interactions-CoulombScattering}) inside the \ac{SL}. These effects are considered to have a small influence, and therefore the fake patterns discussed here are assumed to be generated only by noise.} In the following, these patterns will be called \enquote{fake patterns}.
\paragraph{SL fake patterns}
The selected fake patterns are presented in fig.\ \ref{fig:DTData-SLFakePatterns}. \section{Superlayer pattern fitting}

%    \item Select laterality combination with best goodness of fit

%\section{Superlayer relative time alignment}

%    \item Establish relative time correction
%\end{itemize}
When the hits of a track-like pattern really originate from a passing muon, their timestamps are not random, but related according to the muon path through the superlayer. By making assumptions on the muon path and the drift behavior of the ionization electrons in the drift cells, one can derive a formula that can be fitted to the cell hit timestamps of the pattern. This fit allows the estimation of the muon arrival time, as well as the track position and angle. Also, by considering the goodness-of-fit variable, it is possible to reject noise-induced track-like patterns, if their timestamps are unlikely to match together to any muon path.
\newline This fitting step is done on superlayer level (i.e.\ applied to all track-like superlayer patterns separately), incorporating the timestamps of four cell hits. The combination of the fitted paths to a global muon track is performed in a later step (sec.\ \ref{sec:DTData-GlobalTrackBuilding}).

\subsection{Assumptions and fit strategy}
\label{sec:DTData-SLPatternFitting-Strategy}
\paragraph{Approximations and track description}
There are several simplifying assumptions made for the fitting of the hit timestamps of the found patterns. These assumptions are explained in the following, together with the mathematical description of the muon track. Fig.\ \ref{fig:DTData-SLPatternFit-Illustration} illustrates an example muon track with the created \ac{SL} pattern. The parameters used in the pattern fit as well as the used local coordinate system is highlighted.
\begin{figure}[htb]
    \centering
    \hfill
    \begin{subfigure}[t]{0.45\textwidth}
        \centering
        \includegraphics[width=\textwidth]{SL-PatternFit.pdf}
        \caption{Pattern with track and its parameters $x_0$, $\alpha$ and $T_0$.}
        \label{fig:DTData-SLPatternFit-Illustration-Track}
    \end{subfigure}
    \hfill
    \begin{subfigure}[t]{0.45\textwidth}
        \centering
        \includegraphics[width=0.7\textwidth]{SL-PatternFit-Cell.pdf}
        \caption{Single cell and laterality $L$ definition.}
        \label{fig:DTData-SLPatternFit-Illustration-Cell}
    \end{subfigure}
    \hfill
    \caption{Coordinate system convention and illustration of the parameters of the \ac{SL} pattern fit.}
    \label{fig:DTData-SLPatternFit-Illustration}
\end{figure}
\newline Regarding the muon track, it is assumed to be a straight line, i.e.\ the influence of Coulomb scattering (sec.\ \ref{sec:Interactions-CoulombScattering}) is neglected. In an $x$-$z$-projection (the $x$ axis in this case is perpendicular to the drift cell wire, i.e.\ parallel to the segmentation of the superlayer), one can describe the horizontal position of the muon with the following equation:
\begin{equation}
    x_\mu (z) = x_0 + (z-z_{ref}) \cdot \tan\alpha,
    \label{eq:SLPatternFit-LinearTrack}
\end{equation}
where $x_0$ is the reference position of the muon (at height $z=z_{ref}$) and $\alpha$ is the track angle measured from the $z$-axis ($\alpha=0$ corresponds to a vertical track). The local coordinate system is chosen with the origin at the position of the $ly=3$ wire, therefore it is $z_{ref}=z_{\text{wire},ly=3}$. The angle $\alpha$ is chosen positive towards the left.\footnote{This unusual convention is used here since the $z$ axis points upwards but $(z-z_{ref})$ is negative for the cells below the reference cell.}
\newline The drift velocity $v_\text{drift}$ of the electrons in the cell is assumed to be constant over the whole length. Therefore, the drift distance $x_D$ can simply be related to the drift time $t$ with a linear equation:
\begin{equation}
    x_D = v_\text{drift} \cdot t.
    \label{eq:SLPatternFit-DriftDistance}
\end{equation}
This is of course an approximation, as the electric field in the cell is not completely homogeneous, especially near the anode wire.
\newline The track position $x_\mu(z)$ is now equated with the wire position $x_{\text{wire},ly}$ plus the drift distance $x_D$. As the wire is at the center of the drift cell and the sign of the drift distance $x_D$ can not be determined by the measurement of the drift time $t$, a left-right ambiguity remains. This ambiguity is described with the laterality factor $L=\pm 1$. The sign of the laterality is chosen as follows: $L=-1$ means left ($x<x_\text{wire}$) of the wire, $L=+1$ means right ($x>x_\text{wire}$) of the wire. Fig.\ \ref{fig:DTData-SLPatternFit-Illustration-Cell} above illustrates the definition and sign convention used for the laterality. For the drift cells of the four layers $ly =0,1,2,3$, one can then write down the following equations:
\begin{equation}
    x_\mu (z=z_{\text{wire},ly}) = x_{\text{wire},ly} + L_{ly} \cdot v_\text{drift} \cdot t_{ly}.
    \label{eq:SLPatternFit-xPosition}
\end{equation}
Here, the vertical position of the drifting electrons is assumed to be equal to the height of the respective wire $z=z_{\text{wire},ly}$. In reality however, the muon leaves a track of ionization charges over the full height of the cell, not a localized charge at the height of the wire. Especially for larger muon inclinations, this implies a bias on this fit method.
\newline It is further assumed that the ionization events in all cells happen simultaneously. With this assumption, one can use a common arrival timestamp $T_0$ for the muon track. The recorded timestamps of the cell hits in the four layers $T_{ly}$ can then be related to the drift time $t_{ly}$ for the respective cell as follows:
\begin{equation}
    T_{ly} = T_0 + t_{ly}.
    \label{eq:SLPatternFit-Timestamp}
\end{equation}
\paragraph{Timestamp fit function}
Combining eqs.\ \ref{eq:SLPatternFit-LinearTrack}, \ref{eq:SLPatternFit-xPosition} and \ref{eq:SLPatternFit-Timestamp} yields the following four equations $(ly =0,1,2,3)$ for the cell timestamps $T_{ly}$:
\begin{equation}
    T_{ly} = T_0 + \frac{L_{ly}}{v_\text{drift}} \cdot \left( x_0 + z_{\text{wire},ly} \cdot \tan\alpha - x_{\text{wire},ly} \right).
    \label{eq:SLPatternFit-FitFunction}
\end{equation}
By fitting the measured timestamps $T_{ly}$ to this function, one can obtain the values for the three local track parameters $(T_0,\;x_0,\;\tan\alpha)$. Fig.\ \ref{fig:DTData-SLPatternFit-Illustration-Track} above illustrates the meaning of the three parameters with an example track.
\newline Note that in principle one could use the drift velocity $v_\text{drift}$ as an additional fit parameter, if one uses patterns with four hits. However, in this thesis, the drift velocity is fixed to the known \ac{CMS} reference value of $v_\text{drift}\approx\SI{54.5}{\micro\meter/\nano\second}$ (eq.\ \ref{eq:DT-DriftVelocity}).
\paragraph{Fit method and uncertainties}
The fit method is a least-square minimization ($\chi^2$-fit) which uses the layer index $ly=0,1,2,3$ as $x$-coordinate and the respective hit timestamp $T_{ly}$ as $y$-coordinate. It is clear that, when fitting four timestamps to the three parameters $(T_0,\; x_0,\; \tan\alpha)$, the number of degrees of freedom is $N_{df}=4-3=1$.
\newline The uncertainty of the timestamps $\sigma_{T,ly}$ for the fit is derived from the digitization uncertainty of the \acp{OBDT} ($0.78 \;\si{\nano\second}/\sqrt{12} \approx 0.22 \;\si{\nano\second}$) and the uncertainty of the applied timing correction obtained from the test pulse run (typically $1-2 \;\si{\nano\second}$, sec.\ \ref{sec:DTData-Testpulse-Calibration}). As discussed, the fit function (eq.\ \ref{eq:SLPatternFit-FitFunction}) assumes that the drift electrons are always created at the height of the wire and the drift takes place along the horizontal axis, which is a strong simplification. It is clear that in reality, different (longer) drift times are expected if the electron is created on a different height than the wire, as it has to drift at an angle. Additionally, inclined tracks lead to more complicated drift time behaviors. It is decided to assign an additional generous \SI{5}{\nano\second} of uncertainty to all timestamps to cover for these effects related to the horizontal drift assumption. With this, the total assigned uncertainty of the cell timestamps is in the order of $5-6 \;\si{\nano\second}$.
\paragraph{Laterality combinations}
The value of the four laterality factors $L_{ly}$ is initially unclear, as there are several allowed laterality configurations of the four cells for each pattern (because of the left-right ambiguity of a cell hit). Tab.\ \ref{tab:DTData-SLPatternFit-AllowedLateralities} in the appendix lists all laterality combinations which are geometrically possible for each of the analyzed patterns. As the assumption of one configuration would result in a strong bias for the analysis, the timestamp fit is performed for each laterality combination. Then, only the fit with the best (lowest) goodness-of-fit variable $\chi2/N_{df}$ is kept for the next analysis steps.
\paragraph{Fit parameter bounds and initial values}
The fit parameter values are required to obey certain bounds, which are given by the \ac{DT} chamber construction. The reference position $x_0$ of the track in the superlayer fit is required to be within the drift cell (which ranges $x_0 \in [-21,\,21]\;\si{\milli\meter}$). As discussed above, the parameter $x_0$ is defined as the position relative to the anode wire in the reference cell ($ly=3$). Depending on the laterality of this cell, it must be not only in the cell, but also on the correct side of the wire:
\begin{equation}
    \left.\begin{aligned}
        \SI{-21}{\milli\meter},\;\; & L_{ly=3}=-1 \\
        \SI{0}{\milli\meter},\;\; & L_{ly=3}=+1
    \end{aligned}\right\}
    \leq x_0 \leq
    \left\{\begin{aligned}
        \SI{0}{\milli\meter},\;\; & L_{ly=3}=-1 \\
        \SI{21}{\milli\meter},\;\; & L_{ly=3}=+1
    \end{aligned}\right. .
    \label{eq:SLPatternFit-x0-bounds}
\end{equation}
\newline The track angle $\alpha$ is restricted to the maximum angular acceptance of the selected superlayer patterns (sec.\ \ref{sec:DTData-SLHitPatterns-TrackPatterns}). One can calculate the minimum $ \alpha_{x,min}$ and maximum $\alpha_{x,max}$ allowed track angles for each pattern, which was done in tab.\ \ref{tab:SLPatternFit-AngularRange} in the appendix. Here, the assumption was made that the cell hits are always at the height of the wire, as discussed above. For the track fit, one requires the angle $\alpha$ to lie within the limits for the respective pattern type:
\begin{equation}
    \alpha_{min} \leq \alpha \leq \alpha_{max} .
    \label{eq:SLPatternFit-alphax-bounds}
\end{equation}
The arrival time $T_0$ of the track can be directly constrained by the four cell timestamps $T_{ly}$. It is clear that the arrival time must be before the time of the earliest cell hit and after the time of the latest cell hit subtracted by the maximum possible drift time in the cell $t_\text{drift,max}$ (eq.\ \ref{eq:DT-MaxDriftTime}):
\begin{equation}
    \max \left\{ T_{ly} ; \; ly=0,1,2,3 \right\} - t_\text{drift,max} 
    \leq T_0 \leq
    \min \left\{ T_{ly} ; \; ly=0,1,2,3 \right\} .
    \label{eq:SLPatternFit-t0-bounds}
\end{equation}
%In the case of noise-induced patterns it is possible that these bound on $T_0$ are invalid, as the lower bound may become larger than the upper bound. In such a case, the pattern is rejected from the fit.
\newline As starting value for the fit parameters, the mean value of the upper and lower bound defined for each parameter is used.
\paragraph{Cuts on fit results}
There are cuts applied to the fit results due to the possibility of noise-induced patterns. By applying a cut on the goodness-of-fit variable $\chi^2/N_{df}$, it is possible to reject these noise patterns, when their timestamps can hardly be used to construct a straight line track. The selected cut value in this work is $\chi^2/N_{df}<10$.
\newline Additionally, fits with resulting non-physical drift times should be removed. The drift time $t_{ly}$ can be calculated from the fitted data, using the estimated track arrival time $T_0$ and the cell hit timestamp $T_{ly}$ as ($ly=0,1,2,3$):
\begin{equation}
    t_{ly}=T_{ly}-T_0
    \label{eq:DTData-DriftTime-Hits}
\end{equation}
It is clear that the drift time should be smaller than the maximum drift time $t_\text{drift,max}\approx\SI{385}{\nano\second}$ (eq.\ \ref{eq:DT-MaxDriftTime}) which is given by the drift velocity assumption. In order to cut away \enquote{corner cases}, where the drift time corresponds to exactly zero or the maximum drift time, a cut margin of \SI{2}{\nano\second} (\SI{2.56}{\tu}) is chosen. The cuts applied to the superlayer pattern fits are summarized in tab.\ \ref{tab:DTData-SLPatternFit-Cuts}.
\begin{table}[htb]
    \centering
    \begin{tabular}{|c|c|} 
        \hline
        \textbf{Variable} & \textbf{Condition} \\ \hline
        Goodness-of-fit $\chi^2/N_{df}$ & $\chi^2/N_{df} < 10$ \\ \hline
        \multirow{2}{*}{Drift time $t_{ly}$} & $t_{ly} \geq \SI{2}{\nano\second}$ \\
        & $t_{ly} \leq t_\text{drift,max}-\SI{2}{\nano\second}\approx\SI{383}{\nano\second}$ \\ \hline

\end{table}

In the future, these effects should be further explored to properly deal with them in the reconstruction at the cosmic test stand. Besides, the observed spike in the distribution only consists of $\mathcal{O}(1\%)$ of the fitted patterns.

The \ac{MC} simulation, which was already mentioned and used in previous sections, can propagate tracks through the detector geometry to estimate rates induced by atmospheric muons. Details on the simulation can be found in appendix \ref{sec:Simulation}.

\newline The fitting procedure described above is now applied to the superlayer patterns created by the simulated atmospheric muons. One obtains a fitted pattern rate of around $\SI{450}{\hertz}$ per superlayer (tab.\ \ref{tab:Simulation-SLPatternFit-PatternOccupancies}). A comparison of this simulation value with the pattern rate of around $\SI{400}{\hertz}$ per superlayer in data reveals a significantly better agreement of rates between data and simulation as before the fit.\footnote{Before the fitting, the simulated pattern rate was similarly around $\SI{450}{\hertz}$, while the rate in data was significantly higher with around $\SI{700}{\hertz}$ per superlayer (sec.\ \ref{sec:DTData-SLHitPatterns-TrackPatterns}).} This emphasizes the possibility to cut away noise hits (which are not modeled in the simulation), by pattern fitting and applying the described cuts.
\newline Apart from the rates, one can also compare the shapes of the fit parameter histograms between data and simulation. For the recorded data, these histograms were presented above in fig.\ \ref{fig:DTData-Hist-SLPatternfit}. For the simulation, similar plots can be produced, which are shown in fig.\ \ref{fig:Simulation-Hist-SLPatternfit} in the appendix.
\newline The distributions for the arrival time $T_0$ (data: fig.\ \ref{fig:DTData-Hist-SLPatternfit-t0}, simulation: fig.\ \ref{fig:Simulation-Hist-SLPatternfit-t0}) are both similarly uniform. The track inclination $\tan\alpha$ distributions (data: fig.\ \ref{fig:DTData-Hist-SLPatternfit-tan-alpha}, simulation: fig.\ \ref{fig:Simulation-Hist-SLPatternfit-tan-alpha}) both have a similar Gaussian-like shape.
\newline The shapes of the histograms for the reference position $x_0$ (data: fig.\ \ref{fig:DTData-Hist-SLPatternfit-x0}, simulation: fig.\ \ref{fig:Simulation-Hist-SLPatternfit-x0}) however show significant differences. While the $x_0$ distribution in the simulation is almost flat, there is a large peak observed in data at around $x_0\approx\SI{0}{\mm}$, i.e.\ close to the anode wire. As discussed already, this peak arises (in part) from the non-linear electric field in the proximity of the wire. The simulation does not model this, as it assumes a constant drift velocity over the full drift cell. Therefore, the deviation of the histogram shape between data and simulation can in this case be understood as consequence of the simplifications made in the simulation.
\newline The small spikes in the $x_0$ and $\tan\alpha$ distributions for the data (spikes at $x_0\approx\pm 10.5\;\si{\mm}$ and $\tan\alpha\approx 0$, which were already discussed above), are not present in the distributions for the simulation. This emphasizes the hypothesis stated above, that these spikes may originate from noise patterns, where the fit does not converge properly. Since the simulation does not include any modeling of noise, one also does not observe this feature in the respective distributions. Of course, there are many other possibilities, but the absence of the spikes in the simulation points towards an effect which is only present in data and not the simulation.

\label{sec:DTData-SLFitGrouping}
\paragraph{SL pattern grouping}
One needs to consider the fact that several patterns close in time may be present in the same superlayer. This possibility arises from the implementation of the pattern finding algorithm, which searches for possible patterns after each hit in the event loop (sec.\ \ref{sec:DTData-SLHitPatterns-TrackPatterns}). An additional cell hit close to a real track pattern can therefore cause an additional pattern, being very close in time. When attempting to build global muon tracks, it is necessary to combine the fitted patterns of several superlayers (sec.\ \ref{sec:DTData-GlobalTrackBuilding}). Therefore, multiple patterns close in time within the same superlayer will create ambiguities in global track building. The step of pattern grouping should identify such cases.
\newline All patterns of one superlayer are grouped by the arrival timestamp $T_0$ obtained from the pattern fit (sec.\ \ref{sec:DTData-SLPatternFitting}). The time window $\Delta T_\text{0,max}(\text{SL})$ in which the fitted patterns are grouped is chosen as the maximum drift time $t_\text{drift,max}$ (eq.\ \ref{eq:DT-MaxDriftTime}):
\begin{equation}
    \Delta T_\text{0,max}(\text{SL}) = \max \left\{ \left | T_{0,i,SL} - T_{0,j,SL} \right | ; \; i,j=0,...,N_\text{SL fits}(\text{SL}) \right\} \leq t_\text{drift,max} \approx \SI{385}{\nano\second}.
    \label{eq:DTData-SLFitGrouping-TimeWindow}
\end{equation}
\paragraph{Grouping results}
The grouping of fitted patterns is executed for all three superlayers separately. A histogram of the number of patterns in the created groups $N_\text{fits}(\text{Group})$ is presented in fig.\ \ref{fig:DTData-Hist-SLFitGrouping-Nfit}. It is clear that the majority of patterns are isolated in time, as the number of groups with more than one pattern is almost two orders of magnitude lower than the groups with only one pattern. However, there are rare cases where larger pattern multiplicities are observed, close in time. The most extreme case is one pattern group which contains 40 separate patterns. While multiplicities of few patterns are expected to be induced by noise hits close to the real track pattern, the very high multiplicities might be related to showering effects of high-energy cosmics.

\subsection{Superlayer pattern matching}
\label{sec:DTData-GlobalTrackBuilding-SLPatternMatching}
\paragraph{Temporal pattern matching}
The assumption taken during the local superlayer fits, that the muon track creates ionization charges in all cells of the superlayer at the same time (sec.\ \ref{sec:DTData-SLPatternFitting-Strategy}) is extended to all superlayers. With this assumption, one would in principle expect the track arrival times $T_{0,SL}$ for the superlayer fit groups of all three superlayers to be identical.
\newline To account for slight fluctuations, one matches the patterns together, if the respective arrival times $T_{0,SL}$ lie in the following time window $\Delta T_\text{0,max}(\text{global})\leq\SI{20}{\nano\second}$:
\begin{equation}
    \begin{aligned}
        \Delta T_\text{0,max}(\text{global}) & = \max \left\{ \left | T_{0,SL,i} - T_{0,SL,j} \right | ; \; i,j=0,...,N_\text{SL fits}(\text{SL}) ; \; SL=1,2,3 \right\} \leq \SI{20}{\nano\second}.
    \end{aligned}
    \label{eq:DTData-GlobalReco-TimeWindow}
\end{equation}
\newline This value for the time window was selected, as it is large enough to cover fluctuations of few standard deviations of the fitted arrival times for all the three superlayer fits.\footnote{In sec.\ \ref{sec:DTData-SLPatternFitting-Results}, it was discussed that the obtained uncertainty on the arrival time from the fit is $\sigma_{T_0}<5.5\;\si{\nano\second}$ (tab.\ \ref{tab:DTData-SLPatternfit-Uncertainties}). Therefore, the condition $\Delta T_\text{0,max}(\text{global})\leq\SI{20}{\nano\second}$ leaves comfortable margin for fluctuations of the fit results for the different superlayers.} Note that the patterns used here are only the ones which have passed the grouping step before (sec.\ \ref{sec:DTData-SLFitGrouping}) and were found to be \enquote{isolated} in time within the same superlayer. 
\paragraph{Superlayer selection criteria}
In principle, it would be possible to build a global track when one has at least one superlayer pattern fit in the phi and theta plane. However, in this thesis one requires a matched pattern in all three superlayers. A global track is therefore only reconstructed when all 12 layers of the chamber are hit and three successful superlayer pattern fits are available, which have a comparable arrival time.

\subsection{Reconstruction of global track}
\label{sec:DTData-GlobalTrackBuilding-Strategy}
\paragraph{Compatibility check of phi projections}
Because of the selection criteria, there are two phi superlayer pattern fits (\acp{SL} 1, 3) for each global track to be reconstructed. These should first be checked for compatibility and then combined into one track of the phi superlayer projection. The compatibility check has two aspects:
\newline The slope $\tan\alpha_{SL}$ of both local phi superlayer fits $SL=1,3$ is required to not differ more than a chosen threshold:
\begin{equation}
    \Delta \tan\alpha = \left| \tan\alpha_{SL=1},  - \tan\alpha_{SL=3} \right| \leq 0.1 .
    \label{eq:DTData-GlobalReco-SLPhiMatching-Angle}
\end{equation}
To check whether both fits point to roughly the same position in the chamber, the $x$ coordinates of the intersection points of both local fits $x_{\mu,SL}$ w.r.t. a fixed $z$ position in the chamber are required to lie close to each other:
\begin{equation}
    \Delta x_\mu = \left| x_{\mu,SL=1}(z=z_\text{mean}) - x_{\mu,SL=3}(z=z_\text{mean}) \right| \leq \SI{30}{\milli\meter} .
    \label{eq:DTData-GlobalReco-SLPhiMatching-BasePoint}
\end{equation}
The reference position $z_\text{mean}$ here is approximately the center $z$ position of the \ac{DT} chamber ($z_\text{mean}=\SI{144}{\milli\meter}$ in the chosen coordinate system, cf.\ sec.\ \ref{sec:CoordinateFrame-TimestampFormat}).
\newline The selected threshold values in eqs.\ \ref{eq:DTData-GlobalReco-SLPhiMatching-Angle} and \ref{eq:DTData-GlobalReco-SLPhiMatching-BasePoint} are relatively large, as the $\Delta x_\mu$ threshold value is almost as large as the width of one drift cell. However, these checks should mainly suppress pattern fits occurring at completely incompatible positions of the two superlayers, which is ensured, even with these relatively relaxed threshold values.
\paragraph{Combination of phi projections}
When the two phi superlayer pattern fits have passed the compatibility checks described above, they can be merged into one track in the phi projection plane. While it would in principle be possible to refit the eight hits of the two phi superlayers (\acp{SL} 1, 3), here the parameters are combined in a more simple manner: The slope of the two local track fits ($\tan\alpha_{\phi,SL=1}$ and $\tan\alpha_{\phi,SL=3}$) is averaged, and the base point of the local track (determined by the $x_{0,SL=1}$ and $x_{0,SL=3}$ parameters) is replaced by a new base point which is the average $x$ position of both local tracks at the reference height $z_=z_{mean}$ defined above. Also, the arrival time of both tracks ($T_{0,SL=1}$ and $T_{0,SL=3}$) is simply averaged.
\paragraph{Global track reconstruction}
The combined phi superlayer projection (denoted by index $\phi$) and the theta superlayer projection (denoted by index $\theta$) of the track should now be translated to a global track in the 3D coordinate frame. The definition of this global coordinate system was already discussed in sec.\ \ref{sec:CoordinateFrame-TimestampFormat}.
\newline In the global frame, the track is described with a base point $(x_0,\;y_0,\;z_0)$ and the azimuth $\phi \in [0,\; 2\pi)$ and zenith $\theta \in [0,\;\pi/2)$ angles for a half-sphere. The zenith angle $\theta$ is measured from the $z$-axis and $\theta=\SI{0}{\radian}$ corresponds to a vertical track. The azimuth angle $\phi$ is measured in the $x$-$y$-plane, with $\phi=\SI{0}{\radian}$ pointing along the positive $x$-axis. From the coordinate system convention used in this thesis, it is clear that the phi superlayer projection lies in the $x$-$z$-plane and the theta superlayer projection lies in the $y$-$z$-plane. The transformation for the angles can therefore be calculated as follows:
\begin{equation}
    \phi = \atan2 \left( \frac{\tan \alpha_{\phi}}{\tan \alpha_{\theta}} \right)
\end{equation}
\begin{equation}
    \theta = \arctan \left( \frac{\tan \alpha_{\theta}}{\cos \phi} \right)
\end{equation}
Fig.\ \ref{fig:DTData-GlobalTrack-Illustration} illustrates the global track variables and the angles obtained by the superlayer pattern fits.
\begin{figure}[htb]
    \centering
    \includegraphics[width=0.6\textwidth]{GlobalTrack.pdf}
    \caption{Illustration of the relation of the phi superlayer projection ($x$-$z$-plane) and theta superlayer projection ($y$-$z$-plane) local track angles $\alpha_\phi$ and $\alpha_\theta$ to the global track angles $\theta$ and $\phi$ in the used coordinate frame.}
    \label{fig:DTData-GlobalTrack-Illustration}
\end{figure}
\newline The base point of the global track is constructed from the base points of the two projections. The arrival time of the global track is calculated as the average arrival time of the two projections $T_{0,\phi}$ and $T_{0,\theta}$.
\newline In summary, the reconstructed global track has the following six parameters: The arrival time $T_0$, the angles $(\phi,\;\theta)$ and the base point $(x_0,\;y_0,\;z_0)$. Note that the $z$-coordinate is set to a fixed target height $z=z_{mean}$ (see above), which is the mean $z$-coordinate of the chamber.

\subsection{Global track results}
\label{sec:DTData-GlobalTrackBuilding-Results}
\paragraph{Global track occupancy}
Using the algorithm described above, \num{1656448} global tracks were reconstructed from the recorded data. This corresponds to a global track frequency of $(84.52 \pm 0.07)\;\si{\hertz}$.
\newline Compared to the rate of the fitted patterns in each superlayer (around $\SI{400}{\hertz}$, cf.\ sec.\ \ref{sec:DTData-SLPatternFitting-Results}), this is approximately only $20\%$ of the rate. However, there are several factors which are expected to contribute to a smaller global track rate. Note that the global track reconstruction algorithm described above always requires three fitted superlayer patterns, i.e.\ one cell hit in all 12 layers of the chamber. Due to the cell hit efficiency being smaller than one (sec.\ \ref{sec:CMS-DTPerformance}), it is expected that one or more of the cells are not hit by the passing muon. Even if only one hit is missing this means that one superlayer has no valid pattern, even if there are fitted patterns in the other superlayers. In such cases, no global track will be reconstructed. It is also possible, that the applied cuts on the superlayer pattern fits themselves (tab.\ \ref{tab:DTData-SLPatternFit-Cuts}) lead to the occasional \enquote{loss} of one of the three fitted patterns of a passing muon, and therefore inhibit the global track reconstruction. Additionally, it is clear that the described reconstruction strategy relies on many assumptions and simplifications, especially during the superlayer pattern fits (sec.\ \ref{sec:DTData-SLPatternFitting}). This means that the resulting pattern fits might not always be correct and therefore could be filtered out by the matching criteria of the different superlayers.

\newline For atmospheric muons, one expects a roughly uniform distribution in the azimuth angle $\phi$ (sec.\ \ref{sec:AtmosphericMuons-Dependencies}). When looking at the detector data, it is however important to take into account the geometric acceptance of the setup. As the \ac{DT} chamber is not spherical but a cuboid, this acceptance is not flat. From simple considerations one can conclude that the acceptance of a cuboid with respect to the azimuth angle should be symmetric in the intervals $[0,\;\pi)\;\si{\radian}$ and $[\pi,\;2\pi)\;\si{\radian}$. Also, there should be a larger acceptance along the longer horizontal edge of the cuboid. The exact expectation of the expected histogram shape could be determined with \ac{MC} simulations.
\newline Looking at the distribution of the azimuth angle $\phi$ of the reconstructed tracks in fig.\ \ref{fig:DTData-GlobalTrack-Angles-Phi}, an approximate symmetry in the described intervals can indeed be observed. \newline Additionally, there are narrow spikes in the distribution at angles $\phi\approx\{\pi/2,\;3\pi/2\}\;\si{\radian}$ and smaller spikes $\phi\approx\{0,\;\pi,\;2\pi\}\;\si{\radian}$, whose origin is not initially clear. Given the angle definition in the chosen coordinate frame (sec.\ \ref{sec:DTData-GlobalTrackBuilding-Strategy}), it is clear that these azimuth values correspond to a track lying exactly parallel to the wires of one superlayer. This means that in such a case, one has to have a vertical track ($\alpha=\SI{0}{\radian}$) in \acp{SL} 1 and 3 (phi) or \ac{SL} 2 (theta). In the histogram of the local track angles $\alpha$ of the individual superlayer pattern fits, indeed a spike for the angle $\alpha=\SI{0}{\radian}$ is visible (fig.\ \ref{fig:DTData-Hist-SLPatternfit-tan-alpha}, this was already discussed above). The spike in the azimuth plot is very likely the propagation of the observed spike to this distribution.
\newline The zenith angle $\theta$ for atmospheric muons can be approximately described with a $\propto \cos^2\theta$ dependency (sec.\ \ref{sec:AtmosphericMuons-Dependencies}), which means that vertical tracks are preferred and the number of muons with higher angles decreases. For the real detector, one again needs to consider the angular acceptance, which is expected to decrease with increasing angle for the almost flat chamber. Also, the angular acceptance of the reconstructed and fitted patterns (sec.\ \ref{sec:DTData-SLPatternFitting}) limits the available zenith range.
\newline The observed shape of the zenith angle distribution of the reconstructed global tracks (fig.\ \ref{fig:DTData-GlobalTrack-Angles-Theta}) is qualitatively compatible with the formulated expectations.
%However, quantitative analyses show that the angular dependence is more steep than the $\propto \cos^2\theta$ expectation, which is probably not fully explainable with the acceptance limits of the chamber.
\newline It is concluded that the general shapes of the obtained angular distributions are according to the expectation, although there are artifacts visible which may originate from the simplified reconstruction strategy or the influence of noise hits. The investigation of these features is beyond the scope of this thesis, but should be considered in future work.
\paragraph{Global track uncertainties}
Similar as for the superlayer pattern fit results (sec.\ \ref{sec:DTData-SLPatternFitting-Results}), the order of magnitude of the obtained uncertainties should be briefly discussed. The uncertainties are propagated from the parameter uncertainties of the individual superlayer pattern fits.\footnote{For simplicity, the parameters of the three superlayer pattern fits are assumed as uncorrelated, which might not necessarily be the case. In future work, a more sophisticated error propagation should be implemented. The current approach is therefore (most likely) only capable of estimating the order of magnitude of uncertainty.} If multiple values with uncertainties are combined (e.g.\ during averaging of the superlayer fit arrival times), uncertainties are propagated with the Gaussian method when their deviations are compatible with the individual uncertainties. If this is not the case, the maximum deviation between the combined values is used as a measure of the uncertainty.

\newline The typical arrival time uncertainty is $\sigma_{T_0}\approx\SI{6}{\nano\second}$, which is obviously larger than the timing uncertainty of the single superlayer pattern fits ($\sigma_{T_0,\text{SL fits}}<\SI{3.1}{\nano\second}$, cf.\ tab.\ \ref{tab:DTData-SLPatternfit-Uncertainties}). This means that the individual superlayer pattern fits usually deviate more in their arrival times $T_{0,SL}$ than their individual uncertainties cover.\footnote{According to the prescription in the previous paragraph, one performs Gaussian propagation of uncertainty only if the deviation of the different superlayer patterns are compatible within their uncertainties. In such a case, one expects a reduction in uncertainty for the combined global track. Else, the maximum deviation between the pattern fits is used as global uncertainty. This explains why the global track uncertainty can be higher than the individual pattern uncertainties.} However, the obtained uncertainty value of the global track is still acceptable for the application in this thesis, which is the temporal matching of \ac{DT} tracks to scintillator hits (sec.\ \ref{sec:Combined}). The maximum uncertainty on the timestamp equals the superlayer fit pattern matching window (sec.\ \ref{sec:DTData-GlobalTrackBuilding-Strategy}) of $\Delta T_\text{0,max}(\text{global})$, however relatively few tracks have superlayer fit timestamps deviating this much.
\newline The angular uncertainty histograms show a steeply falling distribution with a tail towards large values (cf.\ figs.\ \ref{fig:DTData-Hist-GlobalTrack-Uncertainties-Phi} and \ref{fig:DTData-Hist-GlobalTrack-Uncertainties-Theta}). The majority of global tracks has values $\sigma_\phi,\;\sigma_\theta<\SI{0.05}{\radian}$, and larger uncertainties are only observed for $\mathcal{O}(1\%)$ of the tracks.
\newline The resolution of the base coordinates of the muon $x_0$ and $y_0$ are in the range $\mathcal{O}(\SI{1}{\milli\meter})$. The uncertainty on $x_0$ is larger because it is constructed from the two individual superlayer phi pattern fits, which apparently deviate more than their individual uncertainties. This is similar as was discussed for the arrival time uncertainty above. Although high uncertainty values are possible, the values $>\SI{10}{\milli\meter}$ are occuring rarely, in $\mathcal{O}(1\%)$ of the cases.
\newline It is clear that one would be able to improve the global track uncertainties with a more sophisticated reconstruction approach, i.e.\ by re-fitting the hits of both phi superlayers instead of simply combining the two fits with the method used here (sec.\ \ref{sec:DTData-GlobalTrackBuilding-Strategy}). However, for the purpose in this thesis, it is concluded that the method is sufficient to reconstruct global tracks from the \ac{DT} chamber hits.
\newline As already done above, it should also be mentioned that the uncertainties discussed here are only these which are propagated from the superlayer fit results. Other systematic effects, which have an impact on the track reconstruction, e.g.\ the value of the drift velocity and the simplifying assumptions used in the track fit, are not considered in this work.

\paragraph{Comparison to cosmic tracks}
As done in the previous analysis steps, one can again compare the obtained rates and obtained parameter histograms for the data with the result of the simulation of atmospheric muon tracks. Further details on the simulation are discussed in appendix \ref{sec:Simulation}.
\newline For the simulation, a reconstructed \ac{DT} global track rate of around \SI{196}{\hertz} is obtained. The value observed in data (around \SI{85}{\hertz}) corresponds only to a fraction of $43\%$. Note however that in the simplified simulation, there are no noise events and the measurement of the timestamps has not modeled uncertainty. It is therefore imaginable, that this observed deviation can (at least in part) be explained with pattern fits not surviving the cuts (tab.\ \ref{tab:DTData-SLPatternFit-Cuts}) applied to the goodness-of-fit variable, because of fluctuations of the timestamps due to measurement uncertainties. The fact that the cell hits in the simulation are evaluated at the height of the anode wire, assuming a purely horizontal drift in the cell, implies a bias. It is clear that in data this is not the case, as the ionization by the muon takes place along the full path through the cell.
\newline A comparison of the shapes of the histograms of the global track parameters between data (figs.\ \ref{fig:DTData-GlobalTrack-ArrivalTimes} and \ref{fig:DTData-GlobalTrack-Angles}) and simulation (fig.\ \ref{fig:Simulation-GlobalTrack-Hists}) gives the following observations: Both for data and simulation, the reconstructed global track arrival time $T_0$ (data: fig.\ \ref{fig:DTData-GlobalTrack-ArrivalTime}, simulation: fig.\ \ref{fig:Simulation-GlobalTrack-ArrivalTime}) is uniformly distributed, and therefore in agreement.
\newline The general shape of the azimuth angle $\phi$ distribution (data: fig.\ \ref{fig:DTData-GlobalTrack-Angles-Phi}, simulation: fig.\ \ref{fig:Simulation-GlobalTrack-Angles-Phi}) is similar in data and simulation: In both cases, it is symmetric in the intervals $[0,\;\pi)\;\si{\radian}$ and $[\pi,\;2\pi)\;\si{\radian}$, as expected. However, the histogram for the data shows additional spikes that are not present in the simulation, which were already discussed above (spikes at $\phi\approx\{\pi/2,\;3\pi/2\}\;\si{\radian}$ and smaller spikes $\phi\approx\{0,\;\pi,\;2\pi\}\;\si{\radian}$). In the preceding discussion, it was suggested that this spike is a propagation of the spike in the track inclination (fig.\ \ref{fig:DTData-Hist-SLPatternfit-tan-alpha}, at $\tan\alpha\approx 0$) of the superlayer pattern fit.
\newline For the zenith angle $\theta$ (data: fig.\ \ref{fig:DTData-GlobalTrack-Angles-Theta}, simulation: fig.\ \ref{fig:Simulation-GlobalTrack-Angles-Theta}), the distributions are observed to both decrease with increasing angles. This behavior qualitatively matches with the expectation for atmospheric muons of a $\propto \cos^2\theta$ dependency (sec.\ \ref{sec:AtmosphericMuons-Dependencies}). Still, the quantitative shape of the distributions in data and simulation is different: The slope in the data histogram is significantly steeper than for the simulation. This means that there are fewer tracks reconstructed with higher zenith angles in data. It might be that this is related to the simple reconstruction assumptions, which consider only horizontally drifting electrons in the drift cells at the height of the anode wire (sec.\ \ref{sec:DTData-SLPatternFitting-Strategy}). For inclined tracks, it is clear that the closest distance between the passing muon track and the anode wire shifts more and more away from the horizontal line between the track and the anode wire. This results in a bias for the track towards smaller inclinations implied by the simple reconstruction assumptions, which might explain the deviation.
\newline In the future, the impact of the simulation and superlayer pattern fitting assumptions should be evaluated in more detail. Then, one might be able to better understand the observed tensions between the data and the simplified simulation performed here. However, the general shapes and behaviors are the same in data and simulation. This is considered sufficient for this thesis, which does not attempt precision measurements but only a proof-of-concept measurement.



\paragraph{Conclusion}
From the discussed timing, angle, and position plots of the global tracks, it is concluded that the developed \ac{DT} track reconstruction strategy described in this chapter is delivering satisfactory results. This work presents the first reconstruction of \ac{DT} tracks at the test stand in Aachen in many years, and for the first time with the Phase-2 minicrate electronics. The developed procedure should be used later in sec.\ \ref{sec:Combined} to evaluate the measurement with the \ac{DT} chamber together with the scintillation detector.
\newline Still, it is clear that there are several aspects which should be investigated or improved in future work concerning the reconstruction algorithm. This includes a more elaborate uncertainty discussion and a better understanding of the observed systematic features in pattern fit results, which however are out of the scope of this thesis. Also, the lower global track rate and the steeper zenith angle distribution compared to the performed simulation should be further understood in the future.
